\# AUTOSAR-Compliant Flash Bootloader (FBL) with ISO 14229 (UDS) \& ISO 15765-2 (CanTp)



A modular, production-grade automotive Flash Bootloader prototype implemented in Embedded C following AUTOSAR Classic layered architecture principles. Validated using an end-to-end Python-based UDS diagnostic client over CAN.
